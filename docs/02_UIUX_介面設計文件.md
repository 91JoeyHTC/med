# 藥輪 App ・ UI/UX 介面設計文件

> 版本 v1.0｜日期 2026-06-23｜對象：設計師、前端工程師
> 目標技術：React + Tailwind（Claude design / Claude artifacts 友善）。本文件提供資訊架構、畫面流程、視覺規格、元件庫與 Design tokens，供 Claude design 直接生成 UI。

---

## 1. 設計總綱

### 1.1 風格定位
神聖、自然、靜定。深色「夜空／土地」基底，輔以四元素色（火/土/風/水）。資訊密度高（盤面複雜）但層次清楚。詩意但不花俏。

### 1.2 體驗目標
- 第一眼看到「完整的圓」即理解這是一個結構系統。
- 知識模式：**點 → 看**，零學習成本。
- 繪盤模式：**填表 → 即時看到盤**，輸入與盤面同畫面、即時回饋。

### 1.3 平台與斷點
- 桌面優先（盤面需空間），完整 RWD。
- 斷點：`sm 640 / md 768 / lg 1024 / xl 1280`。
- `< 1024`：盤面與控制面板上下堆疊；盤面維持正方形置中。

> 月亮節點底色＝其家族元素色；方位節點＝深底＋元素色描邊；路徑節點＝紫色系；天群＝中性紫灰；造物者＝accent-2。

### 2.2 字體
- 中文：`Microsoft JhengHei` / `PingFang TC` / `Noto Sans TC`。
- 標題粗體；盤面節點文字 8–16px；內文 13–14px。
- 行高 1.6；字間距標題 +2px（letter-spacing）。

### 2.3 間距 / 圓角 / 陰影
- 間距階：4 / 8 / 12 / 16 / 24（Tailwind 1/2/3/4/6）。
- 卡片圓角 14px（`rounded-2xl` 近似）；標籤膠囊 999px（`rounded-full`）。
- 卡片邊框 1px `line`；hover 提亮 `brightness(1.25)`。

### 2.4 圖示與語氣
- emoji 點綴克制（☉ 🌙）；避免過度裝飾。
- 文案語氣：溫暖、引導、不命定。

## 4. 畫面與流程

### 4.1 知識模式（Screen K）
- 左：藥輪盤（互動）。右：知識卡（預設顯示造物者）＋「藥輪總論」標籤列。
- **流程**：點盤上節點 → 右側知識卡即時替換 → 卡片平滑捲入視野。
- 空狀態：未點選時顯示「點選盤上任一位置」引導文＋配置說明。

### 4.2 繪盤模式（Screen D）
分三張卡（由上而下）：
1. **① 基本資料**：對象 A/B 下拉、暱稱、生日（月/日 下拉）、「推算本命」按鈕 → 顯示本命結果列。
2. **② 七守護靈落點**：六列固定（天/地/北/東/南/西），每列＝方位標籤＋動物名稱 input＋落點 input（逗號分隔多位置）。下方「繪製/更新盤面」按鈕＋「合盤模式」勾選。
3. **盤面圖例與分析**：每人圖例（家族｜方位｜本命月份＋六守護靈清單）＋家族平衡＋（合盤）相合表。
- **流程**：填生日→推算（盤上標本命三點）→填守護靈→繪製（盤上長出色環與標籤）→看圖例分析。
- **合盤**：勾選後切換對象 B 填第二人，盤面雙色疊合。

### 4.3 流程圖（繪盤）
```
進入繪盤 → 選對象A → 填暱稱/生日 → 推算本命(標方位/家族/月份)
        → 填六守護靈(動物+落點) → 繪製
        →[合盤?] 切B → 重複 → 勾合盤 → 繪製雙色
        → 檢視圖例/家族平衡/相合 →(R1)儲存
```

## 5. 藥輪盤視覺規格（WheelCanvas）

> 核心元件。SVG，`viewBox 0 0 560 560`，中心 (280,280)。座標系：角度 0°＝正上方，順時針。`pol(角度,半徑)` 轉直角座標。

### 5.1 版面（十字輻射）
- **外圈 16 節點**，每 22.5° 一個，半徑 196：
  - 四方位在 0°/90°/180°/270°＝北(上)/東(右)/南(下)/西(左)，節點半徑 25，深底＋元素色描邊，標「方位＋季節」。
  - 十二月亮夾在方位之間（每方位後順時針 3 個），節點半徑 23，底色＝家族元素色，標「編號＋簡名」。順序：北後 13,14,15｜東後 16,17,18｜南後 19,20,21｜西後 22,23,24。
- **四輻條**：中心到四方位的連線；其上各 3 個路徑節點（半徑 12–15，紫色），**編號由外向內**（外側號碼小）：北 25→26→27、東 28→29→30、南 31→32→33、西 34→35→36；標「編號＋名稱」。
- **中央群集**（單環，半徑約 58，7 個衛星節點，半徑 17）：依參考圖排列，順時針自頂端＝ 7 雷鳥(上)、8 蝴蝶(右上)、2 大地母親(右)、3 太陽父親(右下)、4 月亮祖母(左下)、5 海龜(左)、6 青蛙(左上)；家族節點底色＝元素色，天群節點＝中性紫灰。
- **中心**：造物者（半徑 19，accent-2 底、淺紫描邊），標「1 造物者」。

### 5.2 標籤
- 節點內：編號（小）＋名稱（小）兩行；月亮可加星座/家族。
- 文字白色，必要時加深色描邊（stroke 0.6）確保深底可讀。

### 5.3 圖例（盤面下方）
- 四元素/家族色塊：火・雷鳥 / 土・海龜 / 風・蝴蝶 / 水・青蛙 / 路徑 25–36。

### 5.4 繪盤覆蓋層（markers layer）
- **本命三標記**：在本命月份/家族/方位節點外圈畫人物色環（stroke 3），旁標「本命月份／本命家族／本命方位」。
- **守護靈標記**：每個落點節點外圈畫色環＋「方位｜動物」標籤；標籤沿節點向外、多筆向下堆疊。
- **合盤**：A、B 兩色，共用節點以**同心雙環**（B 環略大）區分。
- 環半徑＝節點半徑＋4(＋合盤位移)；標籤字 10px、人物色、深描邊。

### 5.5 互動
- 節點 `hover`：提亮；`cursor pointer`。
- 知識模式點節點 → 載入知識卡。
- 繪盤模式：節點不可點（避免誤觸），由表單驅動。
- （加值）點節點顯示「該位置所有落點守護靈」浮層。

## 6. 元件庫（React 元件清單）

## 7. 互動狀態與微互動
- 按鈕：default / hover（提亮）/ active / disabled（降透明）。
- 輸入：focus 邊框 accent；錯誤（落點非 1–36）紅框＋提示。
- 盤面 marker：繪製時可加 0.2s 淡入。
- 知識卡切換：0.15s 淡入＋平滑捲動。
- Loading（R2 解析）：骨架屏。

---

## 8. 無障礙與多語
- 色彩對比：節點文字加描邊確保 ≥4.5:1。
- 不可只靠顏色辨識家族 → 同時有文字標籤。
- 鍵盤：Tabs、節點（知識模式）可 focus + Enter 觸發。
- SVG 加 `aria-label`；節點 `<title>`。
- 文案先繁中；字串集中管理便於日後多語。

## 9. 內容與文案準則
- 解讀用語：「能量互動模式」「可以觀察」「也許」；禁用「一定」「命中注定」。
- 未涵蓋內容統一文案：「逐字稿未深入／待教材核對」。
- 免責頁腳：非醫療、心理諮商或法律建議。
